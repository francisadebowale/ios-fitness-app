# iOS Fitness & Nutrition App

A native iOS fitness and nutrition tracking application built with Swift and SwiftUI. The project was developed as a personal software project to explore iOS development, nutrition tracking, local AI integration, OCR, data persistence, and user-focused interface design.

## Overview

The app provides a central place for users to log food, track daily nutrition, save commonly used foods and meals, monitor progress, and view nutrition insights.

The project developed from a basic nutrition tracker into a more complete application with features including local AI assistance and nutrition label scanning.

## Features

- Daily calorie and macronutrient tracking
- Protein, carbohydrate, fat and fibre goals
- Manual food logging
- Custom serving sizes and units
- Saved foods and meals
- Favourite foods and meals
- Meal creation and reuse
- Daily nutrition history
- Weight tracking
- Nutrition analytics and insights
- Nutrition label scanning using OCR
- Nutrition label parsing and validation
- AI-assisted nutrition label extraction
- In-app AI assistant
- Local Qwen model integration
- Persistent app data
- Custom iOS interface and app icon

## Technologies

- Swift
- SwiftUI
- SwiftData
- Xcode
- Vision / OCR
- Local AI model integration
- Qwen
- Swift Package Manager

## AI Integration

One of the areas explored in this project was the use of AI directly within an iOS application.

The app integrates a local Qwen model to support AI-assisted functionality, including interpreting nutrition information and providing an assistant experience within the application. The project also combines AI-based extraction with OCR and validation logic rather than relying solely on model-generated results.

## Use of AI During Development

AI tools were used as part of the development workflow, particularly for discussing implementation approaches, debugging issues, researching unfamiliar concepts, and reviewing or improving parts of the code.

AI was used as a development aid rather than as a replacement for the development process. I remained responsible for the application's design, feature decisions, implementation, integration, testing, debugging, and final code. AI-generated suggestions were reviewed and adapted before being incorporated into the project.

This project also gave me practical experience in understanding where AI-assisted development is useful and where developer judgement, testing and verification are still necessary.

## Development

The application was developed iteratively over the summer of 2026. Development progressed from the initial SwiftUI and SwiftData foundation through food logging and saved meals, followed by OCR, local AI functionality, analytics, UI improvements and testing.

## Project Purpose

The main goal of this project was to strengthen my practical iOS development skills.

It provided experience working with application architecture, persistent data, UI design, image processing, AI integration, data validation, debugging and testing within a complete Swift application.

## Status

The project is currently a completed personal project and may continue to receive improvements and experimentation in the future.
